# Новый фронт: что интегрировать, чтобы заменить текущий сайт

Объект — `Max-Sundstrom/iskendy-frontend` `72a0ea8` (16.10.2026). Сверено с табло `4fa8108`. Новый фронт закрывает только гостевые `/` и `/board`; `/tv`, `/staff`, `/stats` остаются старым `index.html` (снимок `a0dc17a`, совпадает с нашим `frontend/` байт в байт).

Статусы: ⛔ блокирует переход · ⚠️ нужно до перехода · 💡 после.

## 1. Продуктовые развилки — решает владелец

Новый фронт сделан по решениям Максима (10-decisions.md), часть расходится с уже принятыми у нас.

| | Вопрос | У нас решено | В новом фронте |
|---|---|---|---|
| ⛔ | Общая очередь на телефоне | скрыта с 18.08: гости смотрят список и не подписываются | вкладка «Табло» в меню, флаг `queueOnPhone` объявлен, но **нигде не используется** — выключить нечем |
| ⛔ | Оценка | «никаких модальных окон — оценка живёт на экране заказа» | `RatingDialog` (Radix Dialog), начинается с эмоции 3 |
| ⛔ | Главная `/` | лендинг, единственная страница в поиске | ввод номера (Q-03, ответ Максима 12.10); лендинг пропадает, для поиска остаются `<title>`, description и `<noscript>` |
| ⚠️ | Теги причин | старые: «долго ждали», «остыло»… — на них «топ тегов» в `/stats` | новые формулировки («Долгое ожидание», «Не то в заказе»…) — статистика тегов рвётся на дату перехода |
| ⚠️ | Сообщение управляющему и вложения | нет такого API | UI есть, отправка честно показывает «недоступно» (Q-31). Либо делать API, либо прятать |
| ⚠️ | Кнопка «Игра — скоро» | — | карточка без перехода. Оставлять ли |
| ⚠️ | Номер заказа после СБИС Presto | iiko: 1–237 за сентябрь–октябрь | ввод принимает только **1–999**; если у Presto номера длиннее — подписка невозможна |

## 2. Бэкенд табло — правки под новый фронт

| | Что | Где |
|---|---|---|
| ⛔ | `/tv`, `/staff`, `/stats` отдавать `legacy.html` напрямую, а не через JS-загрузчик и `document.write` (ТВ в Яндекс.Браузере может не потянуть Safari 15 / Chrome 100) | `backend/main.py`, роуты страниц |
| ⚠️ | `QUIET_PATHS` + `/app/` — иначе каждая загрузка JS/шрифтов попадёт в журнал запросов | `backend/main.py:81` |
| ⚠️ | `Cache-Control: immutable` на `/app/*`, `no-cache` на HTML и `sw.js` | middleware в `main.py` или блок Caddy |
| ⚠️ | `/VERSION` и `/ROUTES.json` раскрывают коммит — решить: оставить (удобно для смоука) или закрыть | статика |
| ⚠️ | Тесты `test_public_surface`: новые файлы (`legacy.html`, `/app/*`, `VERSION`) и noindex на них | `tests/` |
| 💡 | API сообщения управляющему и вложений — требования в `docs/48` фронта | новый эндпоинт |
| 💡 | `ETag`/304 на `/api/status` | `main.py` |
