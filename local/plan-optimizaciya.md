## План по шагам

Порядок — по выгоде на рубль. Каждый шаг отдельным PR, `npm run verify` зелёный, бюджеты не расширять.

| # | Шаг | Выигрыш | Риск |
|---|---|---|---|
| 1 | **Служебные экраны мимо загрузчика.** FastAPI отдаёт `legacy.html` прямо на `/tv`, `/staff`, `/stats` (5 строк в `main.py`), загрузчику остаются `/` и `/board`. | ТВ и касса грузятся как раньше: без 110 КБ JS, без `document.write`, без требований Safari 15 / Chrome 100. Снимает главный риск для ТВ в Яндекс.Браузере | Нулевой: бэкенд и так отдаёт один файл на эти пути |
| 2 | **Кэш на хэшированные файлы.** `/app/*` — `Cache-Control: public, max-age=31536000, immutable`; `index.html`, `legacy.html`, `sw.js` — `no-cache`. Middleware в FastAPI или `header` в блоке Caddy | Повторный визит из QR — без загрузки JS и шрифтов, только `index.html` + `/api/status` | Нулевой: имена с хэшем |
| 3 | **Убрать TanStack Query.** Он обслуживает один опрос и один `config`. Свой `usePoll` (~60 строк) поверх уже существующих `nextInterval` и `connectivity` | ~12–14 КБ gzip из первого JS | Средний: опрос — сердце; тесты `polling.test.tsx` переносятся как есть |
| 4 | **Radix Dialog → нативный `<dialog>`**, Slider оставить. Фокус-ловушка и Esc у `<dialog>` встроены во все целевые браузеры | ~8–10 КБ gzip | Средний: доступность — прогнать сценарии клавиатуры и VoiceOver |
| 5 | **Курсор и GSAP — только на устройствах с мышью.** Импорт `motion/runtime` под `matchMedia('(hover: hover) and (pointer: fine)')`; на телефоне чанк не грузится вовсе | −30 КБ gzip трафика на каждом телефоне (это 95 % гостей) | Низкий |
| 6 | **Шрифты.** Убрать `.woff` (все целевые браузеры понимают `woff2`), latin-подмножества оставить только где есть латиница в макете, Cormorant italic — грузить лениво (он только в акцентах) | −100…150 КБ при холодном визите | Низкий; сверить визуал на 390/834/1440 |
| 7 | **Разрезать `mount`.** Сейчас всё гостевое — один чанк 350 КБ. Отдельно: ввод номера (первый экран после QR), «Мои заказы», табло, помощь | Первый экран — цель ≤ 60 КБ gzip | Средний: порядок загрузки и флаги экранов |
| 8 | **`/api/status` с ETag/304** по `updatedAt` (бэкенд). Опрос раз в 5 с с каждого телефона в зале | Трафик опроса ↓ на порядок в тихие часы | Низкий, но это правка бэкенда — отдельно в табло |
| 9 | **Порядок в репозитории.** `GuestExperience.tsx` 870 строк + CSS 748 → по файлу на экран. Документация 56 файлов процесса Codex/Figma-ночей → оставить README, архитектуру, контракт API, решения | Скорость правок, а не загрузки | Нулевой |

## Как мерить

| Метрика | Цель | Чем |
|---|---|---|
| Первый JS `/` | ≤ 60 КБ gzip | `npm run check:size` (поднять строгость бюджета после шага 7) |
| LCP, средний Android, 4G | ≤ 2 с | Lighthouse с троттлингом, 3 прогона, медиана |
| Повторный визит | 0 запросов статики, кроме `index.html` | DevTools → Network после шага 2 |
| `/tv` | ни одного `/app/*.js` | `curl /tv` = `legacy.html` после шага 1 |

## Чего не делать

- Не ослаблять `check:size` ради «потом сократим».
- Не переносить шрифты на Google Fonts/CDN: CSP и РФ.
- Не заменять опрос вебсокетами ради скорости: 5 с гостю хватает, а Caddy, лимиты и ТВ под опрос уже отлажены.
