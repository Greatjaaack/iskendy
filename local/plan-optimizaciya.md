## Что сделано и почему остальное отложено

- **1 и 2 — в бэкенде табло** (`iskendy_site`, ветка `dev`): `_staff_page()` отдаёт `legacy.html` на `/tv`, `/staff`, `/stats`; `_cache_control()` — `immutable` для `/app/*`, `no-cache` для страниц и `sw.js`; `/app/` в тихих путях лога. Тесты — `TestNovyjGostevojFront`, `TestKesh`. На прод уедет с ближайшим релизом табло; на текущий сайт не влияет (пока нет `legacy.html` и `/app/`).
- **3, 4, 7 — переписывание кода чужого фронта**: меняют опрос, диалоги и порядок загрузки экранов, которые закрыты 750 unit и 570 e2e автора, включая пиксельные сверки с Figma. Делать их до решений по ⛔ (очередь, модалка оценки, главная) бессмысленно — те решения сами перекроят экраны. Порядок: решения владельца → B-баги → шаг 7 → 3 → 4.
- **8** — правка горячего пути табло (`/api/status` опрашивают и старые экраны); отдельной задачей в табло с прогоном `progon.py`.
- **9** — документация автора; удалять у себя значит конфликтовать при каждом `git rebase origin/main`. Решать с автором.

## Как мерить

| Метрика | Цель | Чем |
|---|---|---|
| Первый JS `/` | ≤ 60 КБ gzip | `npm run check:size` (поднять строгость бюджета после шага 7) |
| LCP, средний Android, 4G | ≤ 2 с | Lighthouse с троттлингом, 3 прогона, медиана |
| Повторный визит | 0 запросов статики, кроме `index.html` | DevTools → Network после шага 2 |
| `/tv` | ни одного `/app/*.js` | `curl /tv` = `legacy.html` после шага 1 |

## Чего не делать

- Не ослаблять `check:size` ради «потом сократим».
- Не переносить шрифты на Google Fonts/CDN: CSP и РФ.
- Не заменять опрос вебсокетами ради скорости: 5 с гостю хватает, а Caddy, лимиты и ТВ под опрос уже отлажены.
