## Что работает как в старом сайте

Подписка вводом номера, «Готово» опросом за ≤ 12 с, выдача → предложение оценки, опрос `/api/status` раз в 5 с (4 запроса за 20 с), офлайн-режим с последними данными («Нет интернета… Показываем последние данные»), WebKit-подписка без ошибок, `/tv`, `/staff`, `/stats` через загрузчик открываются без ошибок консоли.

## Как повторить

Сценарии лежат в `local/e2e/`. Запуск при поднятом `stack`:

```sh
docker run --rm --network iskendy-frontend_default -v "$PWD/local/e2e:/e2e:ro" -v /tmp/shots:/out \
  iskendy-frontend-verify sh -c 'cp /e2e/*.mjs /web/ && cd /web && node reverse.mjs'
```
