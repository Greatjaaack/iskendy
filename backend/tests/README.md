# Тесты

```bash
poetry install --with dev     # один раз
poetry run pytest             # весь набор, 120 тестов, ~3 секунды
poetry run pytest backend/tests/test_feedback_claim.py -v
```

Зачем они есть: восемь дыр, закрытых в августе 2026, держатся на восьми местах в
коде. Без тестов любая правка рядом снимает защиту молча, и узнаём мы об этом
как в прошлый раз — когда кто-то проверит руками.

## Что покрыто

| Файл | О чём |
|---|---|
| `test_feedback_claim.py` | отзыв только от того, кто занял номер; лимиты и протухание занятий |
| `test_auth_session.py` | одна сессия кассы, отзыв токена, мусор вместо токена |
| `test_client_ip.py` | разбор X-Forwarded-For во всех топологиях |
| `test_public_surface.py` | что открыто без токена, QR только на свои адреса, скрытый orderId |
| `test_rate_limit.py` | лимиты по адресу и раздельность корзин |
| `test_orders.py` | приём заказа, статусы, дедуп, мягкое удаление |
| `test_logs_and_alerts.py` | шум в логах, схлопывание алертов, маршрутизация по темам |
| `test_revert.py` | откат ошибочной выдачи: метки времени, журнал, список выданных |
| `test_digest.py` | вечерняя сводка: состав текста, ширина таблицы, отправка один раз |
| `test_poller.py` | заказы из iiko: окно свежести, дедуп, тревога о молчании |

## Две вещи, о которые легко споткнуться

**Боевой `.env` в корне.** Pydantic читает его при импорте, и там настоящий токен
бота с адресом рабочего чата. `conftest.py` перебивает всё это переменными
окружения ДО импорта приложения и вдобавок подменяет `notify.send_message`
заглушкой. Не убирать ни то, ни другое: иначе тесты напишут в чат смены.

**Клиент притворяется запросом из-за Caddy.** По умолчанию `TestClient`
представляется адресом `testclient` — это не IP, `_trusted_peer` такому не верит,
и заголовок `X-Forwarded-For` игнорируется. Тесты про адреса тогда зелёные, но
ничего не проверяют. Поэтому фикстура задаёт клиенту адрес из сети docker.

## Проверка мутациями

Тесты проверены возвратом дыр: каждая из десяти правок ловится конкретным
тестом. Если добавляешь тест на новую защиту — сломай защиту руками и убедись,
что он покраснел. Зелёный тест, который не умеет краснеть, бесполезен.
