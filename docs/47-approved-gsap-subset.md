## Реализация

- Loader: оригинальный24pxSVG,360°/1.1с linear, включая исходный глиф loading-кнопок. `aria-busy`, текст и доступное имя сохранены.
- Ticker:60px/с, duration=(измеренная ширина цикла+gap)/60. Длина повторно измеряется после шрифтов и resize. Дубликат декоративный `aria-hidden`; клавиатурный фокус останавливает движение и оставляет native Home/End/Arrow scroll, blur возвращает начало перед продолжением.
- Кнопки и ButtonLink:scale0.98 при нажатии,120мс на сторону, power2.out. Native pointer/keyboard handling сохранён, disabled/loading не отправляет повторное действие.
- Slider:точное Radix value/aria меняется сразу;160мс power2.out только для декоративного индикатора и заполнения. Новый input прерывает предыдущий tween. Оригинальные thumb и пять marks экспортированы из Figma244:511/512/522/532/542/552; native Figma rectangles/точки остаются CSS. Пути SVG не перерисовывались. SHA/source IDs в `src/assets/emotion-slider/MOTION-SOURCE.json`; reduced motion использует прежние полные оригинальные SVG states.
- CompactDock:180мс power2.out; y=фактическая высота+bottom offset. Focus и уменьшение visual viewport при клавиатуре применяются сразу. Внешнее горизонтальное центрирование сохранено; кольцо не возвращено.

Reduced motion полностью статичный, без исключения Loader breathing. Это последнее решение владельца, перекрывающее предложенные в46 параметры. При reduce runtime GSAP не импортируется. Смена настройки убирает существующие tweens. В скрытой странице loops paused, текущие interaction tweens завершены/сняты; callbacks/listeners/ResizeObserver/tweens очищаются на unmount. Async импорт обработан как необязательное улучшение: отказ оставляет рабочий статичный UI. MatchMedia callbacks регистрируются в собственном GSAP context, без круговой связи с родительским useGSAP context; ошибка первой проверки cleanup исправлена. Button/ButtonLink сохраняют внешние React19 refs через useImperativeHandle; регрессия Radix возврата фокуса исправлена и40 проверок dialog/layout/accessibility прошли.

Exact registry dependencies:gsap3.15.0,@gsap/react2.1.2 (ADR018). Добавлены только эти две позиции; существующие версии не изменены, новые plugins/CDN не добавлены. Audit0vulnerabilities.
