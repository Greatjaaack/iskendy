### W0-7 · код загрузчика; ADR-003 остаётся «Требует проверки»

Снимок ради этого не менялся.

### W0-9 · совместимое хранилище и машина заказа

- Ключи/формат legacy сохранены, неизвестные поля сохраняются; патч читает последнюю запись. Номер и дата не меняются устаревшим ответом. Приватный режим и переполнение квоты имеют fallback только в памяти.
- Синхронизация вкладок с одним стабильным listener; повторные подписки/очистка проверены. JWT персонала новый код не трогает.
- Чистая машина покрывает pending (1/4 мин), notFound, preparing/ready, подтверждение выдачи, откат, новый день, однократные сигналы и задержку оценки.
- Подписка только через явный вызов, защита от двойного нажатия, без повторов на 429/бизнес-отказ. После сетевого сбоя claim запись сохраняется без ключа, один claimEnsure выполняется перед оценкой (сценарий E08).
- 159 тестов прошли; строки 100 %, ветви 99.09 % суммарно, включая все заявленные границы.

### W0-10 · единственный владелец опроса

- BoardPoller один владеет query ['board']; потребители читают disabled-query без таймеров. 5 с в активной вкладке / 20 с в скрытой; раздельный backoff; retry=0; возврат во вкладку без отмены/дублирования текущего запроса.
- Связность считает только завершённые запросы, игнорирует отмену, сохраняет время последнего успеха, отдаёт длительность восстановления. Настройки Query заданы явно.
- 170 тестов проходят, включая два потребителя, незавершённый запрос, восстановление и переключение visibility. Покрытие core-модулей выше 90 % строк/ветвей.
- Найден и исправлен нюанс формата legacy: случайный суффикс visit — 6 символов, guest — 8; добавлен точный тест.
- Компонент провайдера подготовлен для гостевых экранов фазы 2; техническая страница W0 остаётся без запросов к API.

### W0-11 · платформенные адаптеры и итог фундамента

- Notification API и неизменённый /sw.js, запрос разрешения только явным методом подписки; ограниченное ожидание worker и корректная деградация. Тексты, тег, звуковые тоны и вибропаттерны сохранены из legacy.
- Метрика только на / и /board. Цели без параметров пользователя; просмотры только по белому списку экранов, без произвольного query. defer=true исключает автоматический дубль первого ручного hit.
- События воронки дедуплицируются, кроме sub_try/sub_fail. В отчёты экрана попадают только заранее сформированные безопасные тексты; не чаще 60 с, строго вне активной подписки.
- Исправлен повреждённый синтетический PNG теста W0-6; настоящий imagetools теперь успешно декодирует/преобразует его.
- Сборка переносима на macOS: архив собирается встроенными средствами Node (USTAR+gzip), без GNU-only флагов. Исходный ZIP поддерживается без .git через source-revision.json с хэшами; изменения обнаруживаются и помечаются dirty.
- 200 unit/integration-тестов проходят; актуальное покрытие выше порогов. Полный browser verify по-прежнему не принят, фазу 1 не начинали.
