# Гостевой фронтенд · Liquid Glass · 15.10.2026

Ветка: `feat/responsive-liquid-glass-20261015`. Рабочая копия: `frontend-mobile`. Перенос утверждённых макетов в React; локальная реализация для приёмки, без пуша, релиза и деплоя. Основной checkout, backend, legacy и service worker не изменены. Зависимости не добавлялись.

## Поведение

- Корневые «Мои заказы», «Табло», «Помощь»: светлое стеклянное меню с розовым выделением. Удержание и перетаскивание линзы выбирает раздел при отпускании; отмена жеста не меняет раздел. Клавиатурные ссылки сохранены.
- После уточнений 16.10 каждый заказ показан полной карточкой; переключение стрелками со счётчиком, без выглядывающей соседней карточки. Детали центрированы, свайп обновляет выбранный заказ после остановки прокрутки. Возврат сохраняет исходный экран. На вложенных экранах нижнего меню нет.
- На общем табло свои номера обведены розовым с общей легендой. Действия добавления заказа и списка сохранены. Игра обозначена «Скоро».
- Колокольчик открывает события текущих заказов и настройки разрешений браузера. Это отображение локально известных текущих статусов, не серверный архив уведомлений. Отметка прочитанного действует в текущей странице.
- Оценка начинается с 3; обе ветки проходят причины и необязательный комментарий. «Другое» открывает уточнение и переносит его в комментарий. Отзыв анонимный. Добавление/удаление файлов доступно и в отзыве, и в сообщении управляющему.
- Форма управляющему не собирает имя и контакты; номер заказа необязателен. Есть проверка пустого сообщения, сохранение ввода при неудаче и подтверждение выхода. Черновики и выбранные файлы живут в памяти страницы, включая внутреннюю навигацию; перезагрузку не переживают.
- Обработаны загрузка, пустые данные, отсутствие сети с последними известными статусами, ошибка сервера с повтором, ненайденный заказ, тост готовности, запрет/отсутствие поддержки уведомлений и ошибки существующего API оценки. Готовность, звук, вибрация, хранение, аналитика и единственный владелец опроса сохранены.
- Button, Input, Sheet и skeleton получили Glass-оформление. Поля и кнопки не обрезают собственные тени. VisualViewport учитывает системную клавиатуру; её изображение не рисуется внутри страницы.

## Бэкенд и приёмка

UI сохраняет выбранные файлы и показывает восстанавливаемую ошибку вместо ложного успеха. После удаления вложений существующий текстовый API отзыва работает. Никакие новые эндпоинты не придуманы.

Далее: Claude Code проводит приёмку и интеграцию по `AGENTS.md`/`CLAUDE.md`; реальная отправка сообщений и вложений требует контракта бэкенда. Служебный `PRODUCT.md` датирован 12.10 и не описывает новый визуальный вариант; актуальные решения находятся в `DESIGN.md`, design sidecar и docs/48. Старая запись `_reviewNotes` в `.impeccable/config.json` не используется текущим Impeccable; конфигурация не менялась как побочный эффект этой задачи.
