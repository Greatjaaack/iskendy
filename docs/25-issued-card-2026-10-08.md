## Реализация

Карточка оценки появляется сразу после выдачи (Q19). Mobile: билет заказа
и карточка 74:197 внутри M5 74:185. Desktop: карточка 81:634 внутри D5 81:580
заменяет билет; остаётся один h1 и одна область с именем «Ваш заказ N».
Пять исходных статичных фотографий занимают 52 px / 72 px, без движения.
Цвет подписи — одобренный Q25 semantic token, точный чёрный, opacity 1.
Тексты вынесены в `src/content/issued.ts` из read-only Figma context.

Кнопка открывает существующий Radix Dialog оценки. Выбор эмоции переживает
Escape и Back; закрытие возвращает фокус к кнопке. Исправлена прежняя
ошибка CSS selector: список `[data-rating-trigger], main h1` выбирал первый
элемент в DOM, то есть заголовок, а не кнопку. Теперь кнопка имеет приоритет.
До действия «Дальше» карточка не создаёт feedback и не вызывает claim.

Напоминание учитывает `config.promptDelaySec`. `promptedAt` записывается
перед независимыми каналами звук/вибрация/уведомление; StrictMode, повторные
тики и перезагрузка не дублируют его. Напоминание возвращает из очереди к
выданному заказу, но не открывает диалог само. Явное открытие кнопкой также
помечает приглашение. Откат статуса позволяет новое напоминание после новой
выдачи; новый день и gone/rated/done не вызывают старое напоминание.
Контракт, имена storage keys и неизвестные legacy-поля сохранены.

Ссылка на Карты доступна независимо от оценки: mobile в Header, desktop
в карточке. Использует существующий safe URL filter, native link с
`noopener noreferrer`; небезопасный адрес скрывает только ссылку. «Отследить
другой заказ» очищает заказ и возвращает фокус к номеру.
