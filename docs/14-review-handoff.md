## Безопасная проверка в другом разрешённом окружении

1. Распаковать исходный ZIP в новую пустую изолированную папку. Не накладывать его
   на основной репозиторий. В архиве нет node_modules, .env, секретов и Git-истории.
   source-revision.json содержит исходный commit и SHA-256 файлов; сборка работает
   без git init и отмечает изменения исходников как dirty.
2. Проверить Node 24.19.0 / npm 11; не менять настройки системы без разрешения.
3. Выполнить `npm ci`, затем `npm run browsers:install`.
4. Выполнить `npm run verify` и `npm audit --omit=dev --audit-level=high`.
5. Сохранить вывод и отчёт Playwright. Не заменять WebKit Chromium-эмуляцией.
6. Просмотреть /, /board?my=1, /tv, /staff, /stats на локальном mock-сервере.
   На первых двух пока техническая страница W0; операционные маршруты должны
   показывать исходные экраны legacy по прежнему URL.
7. Никакого реального входа в кассу. Тестовый HTTP перехвачен локальными фикстурами.
   Реальные телефоны, авторизация legacy, CSP через FastAPI и пользовательские
   сценарии фаз 1–4 не объявляются пройденными по этим smoke-тестам.

## Команды

```sh
npm ci
npm run browsers:install
npm run verify
npm audit --omit=dev --audit-level=high
```

`verify` запускает typecheck → lint → check:tokens → test с coverage → build →
check:size → test:e2e. E2E автоматически поднимает отдельную mock-сборку на 4173
и dev-витрину на 5174. Уже работающие серверы на этих портах нужно остановить,
чтобы не проверить устаревшую сборку.

Производственная сборка — dist/, мок — dist-mock/. MSW и тестовый hook отсутствуют
в dist/. Макетные изображения появятся только после чтения конкретных узлов Figma.

## Что проверить в ADR-003

- Загрузка legacy.html подменяет документ, сохраняя /tv, /staff, /stats.
- React/mount-чанк и Метрика не запускаются на операционных маршрутах.
- Нет ошибок CSP, исходные картинки/шрифты работают.
- Назад/вперёд, повторная навигация, перезагрузка, отмена загрузки и сбой сети.
- Переходы через границу app/legacy обрабатываются загрузчиком
  (src/boot/route-handoff.ts) через reload того же URL. На Mac проверены
  касса → /board и назад/вперёд, без изменения снимка legacy.
- Уведомления через /sw.js требуют реальных устройств. В MSW e2e необходимо
  отдельно подменять регистрацию notification-worker, чтобы она не заменила
  корневой mock-worker; производственный sw.js остаётся точной копией.

ADR-003 остаётся «Требует проверки». Пока нет браузерной и ручной приёмки, это
не готовность к выпуску, не полная совместимость с legacy и не закрытая фаза 0.
