## Изменение

Сборщик получает PURE-аннотации только для именования локальных функций и
класса в проверенном `@radix-ui/react-collection` 1.1.16. `__name` вызывает
`Object.defineProperty` лишь на этих собственных функциях/классе. Неиспользуемые
экспериментальные collection helpers могут удаляться; используемые вызовы
остаются и сохраняют имена. Dialog/Slider, обработчики, фокус, ARIA, scroll lock
и приложение не заменены. Исходные node_modules и backend не редактировались.

Перед преобразованием проверяется SHA256 **всего исходника пакета**.
Обновление пакета с другими байтами остановит build до повторного ревью.
Это точечная поправка metadata tree-shaking, а не глобальное отключение
проверки побочных эффектов. Зависимости и lockfile не изменены.

## Следующее решение

Размер ALL всё ещё превышает предел на 14892 Б. Не найдена дополнительная
проверенная оптимизация текущего стека, которая закрывает это превышение.
Предыдущие измерения Oxc target/maxIterations, manual chunks и router Link
замены описаны в docs/24: улучшения ALL не дали. Не включены широкие unsafe
pure/side-effect предположения, замена React/Router/Query/Zod/Radix или eager
загрузка Rating. Уменьшение initial-графа не объявляется прохождением ALL gate.

Родителю: согласовать с владельцем ADR на отдельный сравнительный эксперимент
с Terser как dev-зависимостью (не обещает достижения лимита), либо определить
допустимый объём архитектурной оптимизации. До согласования зависимости,
архитектура и checker остаются прежними. Вопрос Q-26 — docs/10.
