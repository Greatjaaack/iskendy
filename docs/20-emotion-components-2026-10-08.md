## Поведение

- EmotionCharacter: пять эмоций × lg/sm, WebP 720/180 в слотах 240/72.
  Только статичные изображения; alt задаёт потребитель, по умолчанию декоративный.
- EmotionSlider: controlled Radix Slider, пять дискретных остановок,
  min/max/now/valuetext, стрелки и Home/End, тап по ближайшей остановке.
  Имена персонажей из Figma вынесены в src/content/emotion.ts.
- Haptic 8 ms только при реальной смене значения; неподдерживаемая/заблокированная
  вибрация не мешает взаимодействию. Disabled блокирует изменения.
- Native ширина 342 px, responsive масштабирует исходный SVG пропорционально.
  ResizeObserver выравнивает Radix stop centres с исходными центрами
  28/99.5/171/242.5/314, сохраняя интерактивный thumb 56×56 даже при ширине 272.
  Синий focus-visible 2 px + зазор 2 px. Смена мгновенная, без CSS motion.
