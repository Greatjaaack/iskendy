# Подготовка публичного репозитория · 16.10.2026

Владелец подтвердил открытый GitHub-репозиторий. Публикуется новый снимок текущей
версии, без импорта прежней локальной Git-истории. Прежние 136 коммитов, текущие
исходники до очистки и материалы проверок сохранены в локальном архиве вне репозитория.
Исходный основной checkout не изменялся.

Из публичного состава исключены 1073 файла: старые `review-evidence/`, локальные
метаданные дизайн-инструмента и QR-коды с адресом конкретной Wi-Fi сети.
Рабочие шаблоны интеграционной проверки из `review-evidence/` перенесены в
`tests/integration/backend-fixture/`; runner использует новый путь.
Это не изменение API или бэкенда. Крупные старые результаты проверок не являются
зависимостями приложения. Датированные документы сохраняют исторический контекст;
упомянутые в них старые логи доступны в локальном архиве владельца.

Сохранены исходники, оригинальные ассеты, токены, lockfile, тестовые фикстуры,
сценарии, документация и актуальные визуальные проверки в `docs/reviews/`.
Зависимости, результаты сборок и запусков тестов, браузерные кэши и локальные
настройки исключены через `.gitignore`. Секреты в `.env` не публикуются.

Перед публикацией исходники проверены на ключи, токены и секреты. Три совпадения
были заведомо синтетическими URL с user:password в тестах отказа от небезопасных
ссылок. Реальных секретов этими проверками не обнаружено.
`npm audit` по закреплённому lockfile: 0 известных уязвимостей во всех категориях.
Эта проверка не означает отсутствия любых будущих или неизвестных уязвимостей.

README приведён к текущему состоянию интерфейса, тестов и ограничений backend.
Публикация исходников не является production-деплоем. Деплой и изменения существующего
бэкенд-репозитория не выполняются.

## Проверка чистого снимка

Зависимости заново установлены `npm ci` по неизменённому lockfile. Полный
`npm run verify` в новой папке прошёл: 750 unit/component, 573 E2E, 40 условных
платформенных пропусков. Проверки типов, lint, токенов, сборки и размера прошли.
`npm run format:check` прошёл. Сравнение внутренних Markdown-ссылок: битых ссылок нет.
Финальный набор Git: 635 файлов, без символьных ссылок, секретов по проверенным
шаблонам и файлов размером свыше 50 МБ.

Публичный репозиторий: <https://github.com/Max-Sundstrom/iskendy-frontend>.
README описывает текущий запуск, синтетические сценарии и реальные ограничения.
Проверка видимости и совпадения опубликованного коммита выполняется после push.

Первая облачная проверка обнаружила отличие контейнера GitHub от Mac: Git отказался
читать commit из-за владельца checkout. В CI добавлен `safe.directory` только для
`$GITHUB_WORKSPACE`, а не для произвольных каталогов. Устаревшие Actions заменены
официальными Node 24 версиями, закреплёнными полными SHA (checkout v7.0.1,
setup-node v7.1.0, upload-artifact v7.0.2). Их используемые параметры сверены с
официальными action.yml. Изменения ограничены служебными workflow.
