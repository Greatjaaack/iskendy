# 09 · Дорожная карта

**Роли по умолчанию:** реализует Codex, принимает Claude Code, решения принимает Максим. Исключения отмечены в задаче.

**Правило перехода между фазами:** фаза закрыта, когда выполнены её критерии выхода и Claude Code принял все её PR. Задачи внутри фазы можно делать параллельно, если они не зависят друг от друга.

**Ночью компьютер выключен, и задачи выполняет облачный агент.** Какие задачи можно отдавать на ночь, а какие только днём, и от чего каждая зависит — [12-night-mode.md](12-night-mode.md) §5.

Узлы Figma для экранов — [01-product.md](01-product.md) §4, для компонентов — [05-figma-workflow.md](05-figma-workflow.md) §3.
