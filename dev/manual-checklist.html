Ширины 320/390/768/1024/1440, Tab/Shift+Tab, Enter, Escape, стрелки/Home/End слайдера, Back, повторное открытие GSAP-эффекты пока по roadmap; персонажи остаются статичными
  1. Откройте «Ручные проверки», выберите сценарий. «Начать заново» сбрасывает только подписку этого изолированного стенда.
  2. Проверьте текст, отсутствие обрезки/горизонтального прокручивания внутри интерфейса, видимый фокус, кнопки и ссылки.
  3. В оценке выберите эмоцию, причину, закройте Escape и вернитесь. На текущем снимке открытие оценки доступно через отдельный сценарий.
  4. Повторите на разных ширинах. Узкая рамка не эмулирует настоящий iPhone: сенсорный ввод и VoiceOver требуют проверки на устройстве.
  5. Для отчёта укажите сценарий, ширину, шаги, ожидание и полученный результат. Витрина — компоненты, гостевой сценарий — интеграция.
